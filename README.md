# ДЗ №1 — Мини-трекер учебных задач

**Вариант A (новичок): два независимых чата с одной моделью, прямое задание и спецификация в формате OpenSpec без CLI.**

## Как запустить

1. Скачайте `tracker-v1.html` и `tracker-v2.html`.
2. Дважды щёлкните по любому из файлов или откройте его через браузер.
3. Сервер и установка зависимостей не нужны; CSS и JavaScript включены в каждый HTML-файл.
4. Исходные задачи: «Чтение» — 2 ч (готово); «Практика» — 4 ч (активно); «Повторение» — 2 ч (активно).
5. Выполните проверки T1–T5 по разделу 4 в [`report.md`](report.md). Перед независимой проверкой восстановите начальное состояние задач; если браузер сохранил изменённые данные, можно очистить данные сайта/файла или открыть в новом профиле браузера.

**Модель/режим:** ChatGPT Instant.  
**Дата:** 13 ноября 2026.  
**Отчёт:** [`report.md`](report.md).  
**Промпты:** [`prompts.txt`](prompts.txt).

## Структура

- `tracker-v1.html` — первая реализация по короткому запросу, сохранена без исправлений.
- `tracker-v2.html` — вторая реализация по спецификации, сохранена без исправлений.
- `proposal.md` — цель и границы.
- `specs/tracker/spec.md` — требования MUST и сценарии WHEN/THEN.
- `design.md` — данные, расчёты и интерфейс.
- `tasks.md` — первоначальный план перед реализацией (его чекбоксы сохранены в исходном виде).
- `report.md` — реальные тесты, сравнение, вывод и ограничения.
- `screenshots/` — подтверждения двух начальных экранов в Chromium.

## Примечание о хранилище

Обе версии используют `localStorage`. Возможность сохранения при `file://` может зависеть от браузера. Проверка сохранения между перезапусками не проводилась и не заявлена как пройденная. В v2 предусмотрено продолжение работы в памяти и уведомление, если хранилище недоступно.

## Метод

Для v2 спецификация в формате OpenSpec была подготовлена в веб-чате; **OpenSpec CLI и валидатор не запускались**. Итоговые результаты T1–T5 подтверждены вручную и дополнительными браузерными проверками. Работа не требует установки программ для варианта A.
