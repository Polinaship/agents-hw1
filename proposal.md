# Proposal: Мини-трекер учебных задач
## Цель
Создать автономный мини-трекер для учёта учебных задач на неделю с возможностью добавлять и удалять задачи, отмечать их выполнение, фильтровать список и отслеживать прогресс по часам.
## Результат
Один файл `tracker-v2.html`, содержащий HTML, CSS и JavaScript.
Приложение работает без CDN, внешних библиотек, API-ключей и сетевых запросов.
## Область реализации
- Отображение списка учебных задач.
- Добавление задачи с названием и количеством часов.
- Удаление существующей задачи.
- Переключение статуса выполнения `done`.
- Валидация названия и часов.
- Фильтрация списка по статусу: все, активные, выполненные.
- Подсчёт общих и выполненных часов.
- Отображение прогресса в процентах.
- Адаптация интерфейса к ширине 390 px.
## Начальные данные
| Название | Часы | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |
Начальные показатели:
- Всего: 8 ч.
- Выполнено: 2 ч.
- Прогресс: 25%.
## За пределами реализации
- Серверная часть и база данных.
- Авторизация и учётные записи.
- Синхронизация между устройствами.
- Внешние API и библиотеки.
- Календарное планирование и уведомления.
- Редактирование названия и часов существующей задачи.
- Дополнительная аналитика и графики.
## Необязательное улучшение
Сохранение списка задач в `localStorage` между перезапусками.
При недоступности хранилища приложение должно продолжать работать в памяти и показывать понятное сообщение.
Для страниц, открытых через `file://`, доступность и поведение `localStorage` зависят от браузера и не гарантируются.
## Критерий завершения
Обязательные требования и сценарии приёмки выполнены. Результат представляет собой один автономный HTML-файл.
Реализация и фактическое тестирование выполняются отдельным запросом.
